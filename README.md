# 🚗 안녕하세요, 차량용 ECU 및 임베디드 소프트웨어 엔지니어 안해성입니다.

하드웨어와 소프트웨어의 긴밀한 상호작용을 깊이 이해하고, 차량용 시스템에서 가장 중요한 **안전성(Safety)**과 **신뢰성(Reliability)**을 갖춘 코드를 작성하는 것에 가치를 둡니다.
실제 차량 부품의 신뢰성 검증 환경을 경험하며 통신 및 하드웨어 제어 루틴의 최적화 역량을 키워왔습니다.

---

## ⚙️ Core Competencies
* **임베디드 최적화**: C/C++ 기반 객체의 불필요한 소멸자 오버헤드를 방지하기 위한 참조 전달(Pass-by-reference) 등 메모리 및 부하 최적화 고려 고려
* **차량용 및 산업용 통신**: CAN, LIN, SPI 등의 프로토콜을 활용한 레지스터 레벨의 디버깅 및 데이터 동기화
* **신뢰성 검증**: 차량용 도메인의 DV/PV 테스트 프로세스 이해 및 가혹 환경에서의 하드웨어 제어 신뢰성 검증 경험
